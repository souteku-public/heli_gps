# セットアップ手順（配布先の各局向け）

ヘリGPS音声デコード／スーパー送出システムのインストール手順です。
**外部サービス（Google等）のアカウント連携や API キーは一切不要**、
**インターネット接続なし**で動作します。

---

## ★ 新しいPCでの手順（まずこれだけ）

順番が大事です。**1〜3を飛ばすと起動しません。**

| | やること | 確認 |
|---|---|---|
| **1** | **Blackmagic Desktop Video** を入れて PC 再起動（§1） | Desktop Video Setup でデバイスが見える |
| **2** | **GStreamer** を Runtime・Development とも **Complete** で入れる（§2） | ― |
| **3** | **Python 3.10 以降**を入れる。インストーラで **Add python.exe to PATH に必ずチェック**（§3） | コマンドプロンプトで `python -V` |
| **4** | 配布物を `C:\heli_gps` などに展開する（§4） | ― |
| **5** | **`setup_check.bat` をダブルクリック**（これが依存パッケージの導入と確認をまとめてやります） | 「All good.」と出る |
| **6** | `start_heli_preview.bat` で動作確認 → 本番は `start_heli_gst.bat` / `start_heli_burnin.bat`（§6） | ― |

> ### `setup_check.bat` が全部やってくれます
> `python -m pip install -r requirements.txt` を実行したうえで、
> **Python / numpy / Pillow / tkinter / 同梱データ / 同梱フォント / GStreamer /
> decklink プラグイン**を順に調べ、**足りないものと直し方を日本語で一覧表示**します。
> 起動がうまくいかないときは、まずこれを実行してください。

## 0. 事前に用意するもの

| | 内容 |
|---|---|
| PC | Windows 10 / 11（64bit） |
| キャプチャ | Blackmagic DeckLink / UltraStudio（SDI 入出力） |
| 信号 | ヘリ受信映像の SDI（GPS音声がエンベデッドされたもの） |
| 基準同期 | **REF（ゲンロック）** … SDI 出力を行う場合は必須 |

> **本体の配布物には GStreamer と Desktop Video は含まれていません。**
> ライセンス上の理由から、各局で公式版を導入していただきます（下記 1・2）。

---

## 1. Blackmagic Desktop Video の導入

1. Blackmagic Design の公式サポートページから **Desktop Video** をダウンロード
2. インストール後、**Blackmagic Desktop Video Setup** を起動
3. 使用するデバイスの入出力設定を確認（SDI、1080i59.94 等）
4. PC を再起動

> ### ★ SDI出力を行う場合（Fill/Key・バーンイン）は、ここで2つ設定が要ります
>
> | 設定 | 内容 |
> |---|---|
> | **Reference（基準同期／REF）** | SDI出力には**必須**です。REFケーブルを接続し、Desktop Video Setup で参照入力を設定してください。未設定だと出力が開始できず、**GPS音声の取り込みも一緒に止まります** |
> | **Duplex（半二重／全二重）** | 1枚のカードで**入力と出力を同時に**使います。半二重のままだと本番用バッチだけ動きません。デバイスに応じて設定してください |
>
> プレビュー（`start_heli_preview.bat`）はSDI出力をしないため、
> この2つが未設定でも動きます。**「プレビューは動くのに本番だけ動かない」**
> という症状のほとんどはここが原因です（§9-2）。

---

## 2. GStreamer の導入

1. `https://gstreamer.freedesktop.org/download/` から Windows (MSVC 64-bit) の
   **Runtime installer** と **Development installer** を取得
2. インストール時は必ず **Complete（完全）** を選択
   （`decklink` プラグインが含まれます。Typical では入りません）
3. 既定のインストール先:
   `C:\Program Files\gstreamer\1.0\msvc_x86_64\bin`

**確認**（コマンドプロンプトで）:
```
"C:\Program Files\gstreamer\1.0\msvc_x86_64\bin\gst-inspect-1.0.exe" decklinkvideosink
```
→ プロパティ一覧が出れば OK。`No such element` の場合は Complete で入れ直してください。

---

## 3. Python の導入

1. `https://www.python.org/` から **Python 3.10 以降** をインストール
   - インストーラで **Add python.exe to PATH** に**必ずチェック**
   - 「Customize installation」を選ぶ場合は **tcl/tk and IDLE** のチェックを外さないこと
     （制御UIが tkinter を使います）
2. **確認**（コマンドプロンプトで）:

```
python -V
```

→ `Python 3.12.x` のようにバージョンが出れば OK。
`'python' は認識されていません` と出る場合は PATH が通っていません。
Python を入れ直すか、環境変数 PATH に追加してください。

3. 依存パッケージを導入（**`setup_check.bat` を使えばこの手順は不要**）:

```
python -m pip install -r requirements.txt
```

> **`pip` ではなく `python -m pip` を使ってください。**
> PC に複数の Python が入っていると、`pip` が別の Python 側に入れてしまい、
> 「インストールしたのに No module named ... が出る」原因になります。

**入るもの**

| パッケージ | 用途 | 必須 |
|---|---|---|
| `numpy` | 信号処理（MSK復調）・フレーム合成 | **必須** |
| `Pillow` | テロップ・地図の描画、フォント処理 | **必須** |
| `sounddevice` | PCのマイク/ライン入力から復調する検証ツール用 | 任意 |

> **インターネットに繋がらないPCの場合**
> ネットに繋がる別PCで `python -m pip download -r requirements.txt -d wheels`
> を実行し、`wheels` フォルダごと持ち込んでから
> `python -m pip install --no-index --find-links wheels -r requirements.txt` を実行します。
> 社内プロキシ経由なら、先に `set HTTPS_PROXY=http://プロキシ:ポート` を指定してください。

## 5. フォントについて

**配布物には Noto Sans JP（SIL OFL・可変フォント）が同梱済み**です
（`fonts\NotoSansJP-VF.ttf` ＋ ライセンス全文 `fonts\OFL.txt`）。
これが**最優先**で使われるため、**全局で同一の見た目**になります。
文字の太さは制御UIの「見た目 → 文字の太さ」で変更できます（既定 Bold）。

> `fonts\OFL.txt` は OFL の必須条件です。**削除しないでください。**

置かれていない場合は次の順で自動選択します。

1. `fonts\`（同梱）
2. **OFL / IPA 系**（Noto Sans JP、IPAゴシック等） ← 推奨
3. 環境依存フォント（游ゴシック、メイリオ等）

### ★ フォント一覧に出るもの・出ないもの

制御UIのフォント一覧は、既定で**ライセンス上そのまま放送に使えるものだけ**を表示します。

| 表示される | 区分 |
|---|---|
| `fonts\` の同梱フォント（Noto Sans JP） | SIL OFL。**放送・配布とも制限なし** |
| **Windows 同梱フォント**（游ゴシック・メイリオ・MS ゴシック・BIZ UDゴシック等） | 正規ライセンスのWindows上で、文字を映像に描画する用途は追加契約不要 |

**後からインストールしたフォント（モリサワ等の市販フォント）は既定で表示されません。**
放送利用に別途ライセンス契約が必要な場合があるためです。必要なときだけ
「**その他のフォントも表示（EULA要確認）**」にチェックを入れてください。
チェックを入れると一覧に `［要確認］` 付きで現れます。

> **`［要確認］` のフォントを放送に使う前に、必ず自局でそのフォントの
> ライセンス（EULA）を確認してください。**

なお、日本語字形を持たないフォント（欧文専用）は常に除外されます
（選ぶとテロップが消えるため）。詳細は `fonts\README.md`。

## 6. 起動

用途に応じてバッチをダブルクリックしてください。**送出本体と制御UIが同時に起動**します。

| バッチ | 内容 | 外部キーヤー |
|---|---|---|
| `start_heli_preview.bat` | 入力映像＋テロップを**PC画面で確認**（SDI出力なし・REF不要） | ― |
| `start_heli_gst.bat` | **Fill/Key 出し**（スイッチャー側で合成） | 必要 |
| `start_heli_burnin.bat` | **バーンイン**（入力映像＋音声にテロップを焼き込み、1本のSDIで出力） | 不要 |

> ### バーンインは 1080i のまま出します（画質は落ちません）
>
> 入力映像には**一切手を加えません**。1080i のまま静止テロップを両フィールドに
> 重畳し、1080i で出力します。デインターレースによる解像感の低下はありません。
>
> テロップ合成に使う `compositor` は、**2つの入力でインターレース指定が
> 食い違うと交渉に失敗します**（`not-negotiated`）。そこで入力を変換するのではなく、
> **テロップ側を interleaved と名乗らせて揃えて**います。
>
> 万一この構成で映像が出ない場合のみ、バッチの `EXTRA` に `--deinterlace` を
> 指定してください（入力をプログレッシブに変換します。**解像感は落ちます**）。

### 表示項目（住所・時刻・局名）

制御UIの「**表示項目**」でそれぞれ ON/OFF できます。**時刻と局名の既定はOFF**です。

| 項目 | 内容 | 既定 |
|---|---|---|
| **住所** | ヘリ位置から判定した市区町村名 | **ON** |
| **時刻** | 送出PCの現在時刻。粒度（分まで／秒まで）と日付（なし／`11/4`／`11月4日`）を選択 | **ON**（分まで・日付なし） |
| **局名** | 「局名の文字」に入力した固定文字列 | **ON**（`日本テレビ`） |

**既定では3項目とも同じ位置・同じ文字サイズ・同じ色で、画面左下に縦並び**で出ます。

```
千葉・鴨川市上空
12:34
日本テレビ
```

3項目は「**見た目**」セクションに**横並び**で並んでおり、それぞれ独立に
フォント・サイズ・太さ・揃え・色・フチ・透過率・位置を設定できます。

3項目は**それぞれ独立に**、位置・フォント・文字サイズ・太さ・文字揃え・
文字色・フチ色・フチの太さ・**透過率**を設定できます。
「見た目」セクションの先頭にある「**編集する項目**」で切り替えてください。
「配置」のプレビュー上で**つかんだ項目が自動的に編集対象になります**。

- **透過率**: 100%＝不透明。Fill/Key 出しでは、この値が**そのままキー信号**に
  なるため、スイッチャー側でも意図どおり半透明で抜けます
- **ダークモード／文字サイズ**: 画面右上で切り替えます（小・中・大。既定は「大」）。
  全画面の操作卓で離れて見る想定の既定です
- **「縦に並べ直す」**ボタン: 文字サイズを変えて行が重なったときや、
  位置をバラバラに動かしたあとに、編集中の項目を基準にして**上から順に重ならないよう
  並べ直します**
- 設定はすべて「**決定（反映）**」で反映され、「既定として保存」と
  番組プリセットの両方に保存されます

### 住所の見せ方

「住所」セクションの「**住所の見せ方**」で、文字の出かたを変えられます。
設定するとすぐ下に**見本**が出るので、放送に出す前に確認できます。

| 設定 | 内容 |
|---|---|
| 「県・都・府」を省く | 千葉県 → 千葉（**北海道はそのまま**） |
| 「市・区・町・村」を省く | 鴨川市 → 鴨川（市川市 → 市川のように、名前の一部は残ります） |
| 区切り | 都道府県と市区町村のあいだ。なし／`・`／スペース |
| 海上の表記 | 海上にいるときに付ける語。`沖`／`沿岸`／付けない |
| 末尾に付ける | `上空` など。**チェックを外すと付きません** |
| **海上のときは末尾を付けない** | 「沖」「沿岸」が付いたときだけ末尾（`上空`）を省きます。「茨城・鹿嶋市沿岸上空」→「茨城・鹿嶋市沿岸」 |

組み合わせ例:

| 設定 | 陸上 | 海上 |
|---|---|---|
| **既定**（県を省く／市区町村は残す） | **千葉・鴨川市上空** | **茨城・鹿嶋市沖上空** |
| 海上を`沿岸`に | 千葉・鴨川市上空 | 茨城・鹿嶋市沿岸上空 |
| 上記＋「海上のときは末尾を付けない」 | 千葉・鴨川市上空 | **茨城・鹿嶋市沿岸** |
| ＋「市・区・町・村」も省く | 千葉・鴨川上空 | 茨城・鹿嶋沿岸 |
| 県も省かない＋区切りなし（従来形） | 千葉県鴨川市上空 | 茨城県鹿嶋市沖上空 |
| 「末尾に付ける」OFF | 千葉・鴨川市 | 茨城・鹿嶋市沖 |

「住所の粒度」（都道府県／市町村／区あり／区・郡あり／町丁目）と組み合わせて使います。

> ### ★重要：時刻を放送に出す場合は PC の NTP 同期が必須です
>
> ヘリから届く NNN フォーマットのパケットには**時刻が含まれていません**
> （DATA 20バイト＝測位状態4＋緯度6＋経度7＋高度3）。そのため時刻は
> **送出PCの時計**をそのまま表示します。
>
> Windows 標準のインターネット時刻同期は精度が粗く、数秒ずれることがあります。
> **局内の NTP サーバ、または GPS 時刻サーバへ同期**してから運用してください。
> 秒表示にする場合は特にご注意ください。

### 地図（PC上で位置を見る）

> ### ★ 地図が放送に出ることはありません
>
> 地図を放送映像に重ねる機能は**削除済み**です。送出側のコードに合成経路が
> 存在しないため、設定ミスで地図が出る事故は起こりません。

ヘリの位置は**PC画面で**次の2通りで確認できます。

| 方法 | 内容 |
|---|---|
| 制御UI右上の「**地図**」ボタン | 地図ウィンドウが開き、ヘリ位置を表示します |
| `start_heli_preview.bat` | 入力映像＋テロップをPC画面で確認（SDI出力なし） |

**初回は `start_heli_preview.bat` での確認を推奨します**（SDI出力を行わないため安全）。

### バッチ内の設定項目（先頭付近）

| 変数 | 意味 | 既定 |
|---|---|---|
| `CHANNEL` | GPS音声のチャンネル（**0始まり**。CH3なら `2`） | `2` |
| `MODE` / `VMODE` | 出力／入力の信号フォーマット | `1080i5994` |
| `INDEV` / `OUTDEV` | DeckLink のデバイス番号 | `0` |
| `AVOFFSET` | バーンイン時のA/V補正[ms]（+で音声を遅らせる） | `0` |
| `GST1` / `GST2` | GStreamer のインストール先 | 既定パス |

## 7. 動作確認の順序

0. **GPSが受かるか（SDI出力なしで確認）** — `check_signal.bat` を実行。
   `[gps] packets=` が増えれば入力側は正常です（REF不要・安全）
1. **音声が来ているか** — 送出本体のコンソールに `[audio] ch levels(CH1..)` が出ます。
   GPS音声のチャンネルだけレベルが立っていることを確認
2. **復調できているか** — `[status] 受信=True packets=…` が増えていく
3. **住所が出るか** — 制御UIの「受信状態」に市区町村名が表示される
4. **テロップの見た目** — プレビューで位置・サイズ・色を調整し「**決定（反映）**」
5. **SDI出力** — Fill/Key またはバーンインのバッチで送出

## 8. 運用上の既定値（変更しないでください）

| 設定 | 既定 | 理由 |
|---|---|---|
| 住所変換モード | **オフライン** | 同梱データで完結。外部APIに依存しない |
| 地図 | **オフライン地図** | ネット接続・アカウント不要 |
| 地図の放送出し | **機能ごと削除済み** | 地図が放送に出ることはありません。位置確認はPC画面で |
| フォント | **同梱 Noto Sans JP** または Windows同梱 | `［要確認］`のフォントは使用前にEULA確認 |

> 「オンライン（地理院API）」モードは**検証用**です。常用しないでください
> （提供元の想定用途を外れ、可用性の保証もありません）。

## 9. よくあるトラブル

| 症状 | 原因・対処 |
|---|---|
| **バーンインで `not-negotiated` / `Internal data stream error`** | 入力映像とテロップで**インターレース指定が食い違う**と出ます。既定では自動で揃えます。解消しない場合のみ `EXTRA=--deinterlace` を試してください（画質は落ちます） |
| **`Failed to connect to host '127.0.0.1:5001'`** / `接続できませんでした` | gst から本体への localhost 接続ができていません。**ヘリGPSの別の窓が開いていないか**確認して全部閉じ、やり直してください。使用中のポートは自動で空きに切り替わります（`[port] …を使います` と表示）。それでも出る場合はファイアウォール/セキュリティ製品が loopback を遮っていないか確認 |
| **プレビューは動くが、本番用の2つでGPSを受信しない** | **§9-2 の切り分け手順**を実施してください。多くは出力側（REF／Duplex／デバイス競合）が原因で、出力が失敗すると**音声取り込みも一緒に止まります** |
| **`ModuleNotFoundError: No module named 'numpy'`**（または `'PIL'`） | **依存パッケージが未導入**。`setup_check.bat` をダブルクリックしてください。手動なら `python -m pip install -r requirements.txt` |
| `No module named 'tkinter'` | Python のインストール時に tcl/tk が外れています。Python を「Modify」→ **tcl/tk and IDLE** にチェックを入れて入れ直す |
| インストールしたのに `No module named ...` が消えない | PC に複数の Python があり、別の Python に入っています。**`pip` ではなく `python -m pip`** を使ってください。`python -c "import sys;print(sys.executable)"` でどの Python が動いているか確認できます |
| `'python' は認識されていません` | Python 未導入か PATH 未設定。インストーラで **Add python.exe to PATH** にチェックして入れ直す |
| 黒い画面が一瞬で消えて読めない | `setup_check.bat` を実行してください（結果が残ります）。起動バッチのエラーも `pause` で止まるようにしてあります |
| 使いたいフォントが一覧に無い | 後入れフォント（市販フォント等）は既定で非表示。「その他のフォントも表示（EULA要確認）」にチェック。**使用前にEULAの確認を** |
| 時刻がずれている | 送出PCの時計そのものです。**局内NTP／GPS時刻サーバへ同期**してください（§6） |
| `'gst-launch-1.0' は認識されていません` | GStreamer 未導入か PATH 未設定。バッチの `GST1`/`GST2` を実環境に合わせる |
| `No such element decklinkvideosink` | GStreamer を **Complete** で入れ直す |
| `Audio src needs a video src` | 音声だけでは動きません（映像入力が必要）。SDI入力を接続 |
| テロップが出ない／消える | フォントの問題が多いです。UIでフォントを選び直して「決定」。`fonts\` の同梱フォント推奨 |
| SDI出力が乱れる／`Failed to schedule frame` | **REF（基準同期）**が入っているか確認 |
| 音声が途切れて復調が不安定 | 入力レベルとケーブルを確認。コンソールの ch levels が断続的に 0 になっていないか |
| バーンインで音声がずれる | バッチの `AVOFFSET` を調整（+で音声を遅らせる） |

## 9-2. ★プレビューは動くのに、本番用でGPSを受信しない場合

### まず知っておいていただきたい仕組み

**送出本体は、映像入力・GPS音声・映像出力を「1本のパイプライン」で動かしています。**
そのため、

> **映像出力(SDI)の初期化に失敗すると、パイプライン全体が停止し、
> 同じパイプラインの中にある GPS 音声の取り込みも一緒に止まります。**

つまり「**GPSを受信しない**」という症状でも、**原因は出力側にあることが大半**です。
プレビューには SDI 出力が無いので、入力だけなら問題なく動きます。

### 手順1: 入力か出力かを切り分ける

**`check_signal.bat` をダブルクリック**してください。
SDI出力を一切行わず、**GPS音声の受信だけ**を確認します（REF不要・安全）。

> 実行前に、本番用のバッチ（Fill/Key・バーンイン）とプレビューは**すべて閉じて**ください。
> 1枚のDeckLink入力を2つのアプリから同時に開くことはできません。

| 結果 | 意味 | 次に見る場所 |
|---|---|---|
| `[gps] packets=` が**増えていく** | **入力側は正常**。原因は**出力側** | → 手順2へ |
| `packets=0` のまま。`[audio] ch levels` は出る | 音声は来ているが復調できない | → 手順3へ |
| `[audio] ch levels` が**出ない／全ch 0.000** | 入力が取れていない | → 手順4へ |

### 手順2: 出力側のチェック（`check_signal.bat` でGPSが受かった場合）

本番用バッチを起動し、**コンソールのエラー行**を確認してください。
停止時には原因の見立てが日本語で表示されます。

| # | 確認項目 | 見かた・対処 |
|---|---|---|
| 2-1 | **REF（基準同期）が入っているか** | SDI出力には**必須**です。`Failed to schedule frame` が出ていたらこれ。REFケーブルと Desktop Video Setup の Reference 設定を確認 |
| 2-2 | **DeckLink が入出力を同時に使える設定か** | Desktop Video Setup の **Duplex（半二重／全二重）** 設定。半二重のカードは入力と出力を同時に使えません。**これが本番2つだけ失敗する最も多い原因です** |
| 2-3 | **デバイスの競合** | プレビューや Media Express、もう一方の起動バッチが開いていませんか。`Device is already in use` が出ていたらこれ |
| 2-4 | **出力フォーマット `MODE`** | バッチ先頭の `MODE`（既定 `1080i5994`）がスイッチャー側と一致しているか |
| 2-5 | **入出力のデバイス番号** | `INDEV` / `OUTDEV`。1枚で入出力を兼ねるなら両方 `0`、別ポート／別カードなら分ける |
| 2-6 | バーンインの場合 | 入力と出力の両方を同時に使うため、**全二重対応のカードが必要**です |

> **切り分けのコツ**: `INDEV` と `OUTDEV` を**別のデバイス番号**にできる環境なら、
> それだけで動くことがあります（2-2 / 2-6 の裏付けにもなります）。

### 手順3: 復調できない場合（音声は来ている）

| # | 確認項目 | 対処 |
|---|---|---|
| 3-1 | **GPS音声のチャンネル** | `[audio] ch levels(CH1..)` を見て、**値が立っているch**を確認。バッチの `CHANNEL` は**0始まり**です（CH3なら `2`） |
| 3-2 | **入力レベル** | 値が極端に小さい／`1.000` に張り付いている（過大）と復調できません |
| 3-3 | **ビットレート** | 制御UIの「ビットレート」が 1200 / 2400 のどちらか合っているか |
| 3-4 | **音声が断続していないか** | ch levels が周期的に 0.000 になる場合、ケーブルや入力段を確認 |

### 手順4: 入力が取れない場合

| # | 確認項目 | 対処 |
|---|---|---|
| 4-1 | **`VMODE`（入力フォーマット）** | バッチ先頭の `VMODE` を**実際に入っている信号**に合わせてください（既定 `1080i5994`）。`auto` は、カードが自動検出に対応していないと失敗します |
| 4-2 | **`INDEV`（入力デバイス番号）** | 複数ポート／複数カードのときは番号を変えて試す |
| 4-3 | **接続（`--vconnection`）** | 既定は `sdi`。光やHDMIなら変更が必要 |
| 4-4 | **SDIが来ているか** | Blackmagic **Media Express** で映像が見えるか確認（確認後は必ず閉じる） |

## 10. ★重要：表示される地名の限界（必ず運用者へ周知）
