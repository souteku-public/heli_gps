同梱フォントのライセンスを、**フォントファイル内部の name テーブルを直接読んで**確認しました。

|---|---|---|
| 1 / 16 | ファミリー名 | `Noto Sans JP` |

| 0 | 著作権 | `(c) 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.` |
| **13** | **ライセンス** | **`This Font Software is licensed under the SIL Open Font License, Version 1.1.`** |
| 14 | ライセンスURL | `http://scripts.sil.org/OFL` |
| — | 可変軸 | `wght` 100–900（Thin〜Black の9インスタンス） |
| — | グリフ数 | 17,936 |
| — | **OS/2 fsType** | **0 = Installable Embedding（埋め込み制限なし）** |

### 4-1. なぜ放送で使えるのか

**SIL OFL 1.1 が制限しているのは「フォントソフトウェアそのものの再配布」であって、
フォントで組んだ出力物（レンダリング結果）ではありません。** OFL 本文にも
"The requirement for fonts to remain under this license does not apply to any
document created using the Font Software." とあります。したがって

- 放送画面に文字を出す ＝ **制限なし・クレジット不要・許諾不要**
- 商用利用 ＝ **可**
- `fsType = 0` なので、PDF や映像ファイルへの埋め込みも技術的・法的に制限なし

これは**市販フォントや Windows 同梱フォントとの決定的な違い**です。
モリサワ等の市販フォントは放送利用に別途ライセンスが必要な場合があり、
游ゴシック・メイリオ等は**再配布が不可**なので系列局配布ができません。
OFL フォントを同梱しているのは、この2点を同時に解決するためです。

### 4-2. 守るべき OFL の義務（3点だけ）

| # | 義務 | 本プロジェクトの状態 |
|---|---|---|
| 1 | フォントを配布する際は**ライセンス全文を同梱** | ✅ `fonts/OFL.txt`（4,388 bytes）を同梱。削除禁止と各所に明記 |
| 2 | **フォント単体を有償販売しない**（ソフトへの同梱配布は可） | ✅ 無償配布・同梱のみ |
| 3 | **Reserved Font Name を改変版に使わない** | ✅ RFN は `'Source'`。当方はその名称を使わず、フォントも**バイナリ無改変**（ファイル名を `NotoSansJP[wght].ttf` → `NotoSansJP-VF.ttf` に変更しただけ。OFL はファイル名を規制しない） |

### 4-3. 「ふちどり」「太さ変更」は改変にあたるか → **あたりません**

制御UIの「文字の太さ」は可変フォントの `wght` インスタンスを選ぶ操作
（Pillow の `set_variation_by_name`）、縁取りは描画時のストロークで、
いずれも**フォントファイルを書き換えていません**。OFL の「Modified Version」は
フォントソフトウェア自体の改変を指すため、該当しません。

### 4-4. 各局で別のフォントを選んだ場合

制御UIではシステムフォントも選べます。**その場合は当該フォントのEULAが適用され、
放送利用の可否は各局の責任**になります。同梱の Noto Sans JP を使う限り、
**全局同一の見た目**かつライセンス上安全です（`README_SETUP.md` §5）。

### `muni.json` を国土数値情報由来に置き換える選択肢（任意）

N03 の属性には市区町村名そのもの（`N03_004` 等）が含まれているため、
`muni.json` を N03 属性から生成し直せば、**依存先を国土交通省だけに一本化**できます。

出典表記の観点では、国土地理院分がすでに免除されている（問合せ番号 91803）ため
**急ぐ必要はありません**。ただし、依存先が1つになると
「地図スーパーON」「系列局配布」といった使用形態の変更のたびに
**照会先が1か所で済む**という運用上の利点があります。
