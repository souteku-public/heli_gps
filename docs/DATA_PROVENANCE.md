#### 約款の要点（アーカイブ本文より）

> 「コンテンツ」は、どなたでも……**複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。商用利用も可能です。**

つまり本用途に必要な行為は、条件付きで**明示的に許可**されています。

| 行為 | 可否 | 条件 |
|---|---|---|
| 加工（簡略化・再圧縮） | ○ | 加工した旨の記載 |
| **公衆送信（放送）** | **○** | 出典記載 |
| 商用利用 | ○ | 出典記載 |
| **複製物の再配布**（系列局への配布） | ○ ※ | 「**商用可**」区分のデータであること＋出典記載 |

> ※ 約款は指標群ごとに「商用可」「非商用」の区分があり、**「非商用」は複製物の再配布が除外**されます。
> **行政区域データがどちらの区分かをダウンロードサイトで確認し、下欄に記録してください。**
>
> - 行政区域データの区分: **要確認・記入**（商用可 / 非商用）

#### 満たすべき義務（3点）

1. **出典の記載**
   ```
   出典：「国土数値情報（行政区域データ）」（国土交通省）（URL）（取得年月日）
   ```
2. **編集・加工した旨の記載**（出典とは別に）
   ```
   「国土数値情報（行政区域データ）」（国土交通省）（URL）を加工して作成
   ```
   国が作成したかのような態様で公表・利用してはいけません。
3. **適用限界の継承・伝達**（約款 第2条）
   > 空間的には代表点が街区・大字レベル（**概ね数100メートル**）の公差を持ち、
   > 時間的には **1〜5年程度のタイムラグ**を有する。
   > これを**中間加工者から最終利用者まで継承・伝達**すること。

   → 本システムでは `TERMS_OF_USE.md` と `README_SETUP.md` に明記し、系列局へ伝達します。

#### 実装への反映

- 地図スーパーの画面内クレジット（`gst_heli/map_render.py` の `CREDIT_TEXT`、**消去不可**）:
  `出典:国土数値情報(国土交通省)を加工して作成`
  → 出典と加工の両方を1行で満たす。枠幅に応じて自動縮小し、切れないようにしている。
- 住所テロップのみ（地図OFF）の場合は画面内表記に代えて**番組クレジット等**で掲出（掲出方法は法務確認事項）。

## 3. 更新時の手順

データやフォントを差し替えたときは、**必ず**次を実施してください。

1. 新しいファイルの SHA-256 を計算し、本書の表と `docs/terms/data_hashes.json` を更新
2. 原典の**取得日**と**約款の版**を記録（約款ページを `docs/terms/` に保存）
3. 約款の要点に変更がないか確認（特に再配布・公衆送信の可否、出典表記の様式）
4. 変更点を `docs/LICENSING.md` に反映
