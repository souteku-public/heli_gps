# ライセンス整理 — Phase 1(社内モニタのみ)/ Phase 2(放送使用)

本書は、ヘリGPSスーパーシステムを **系列局へ無償配布** し運用するにあたっての
ライセンス・利用規約上の論点を、**段階(フェーズ)別**に整理したものです。

> **免責**: 本書は技術担当による整理であり、法的助言ではありません。最終判断は
> 各利用規約の**原文**と貴社法務でご確認ください。規約は改定されるため、
> **利用時点の条文を保存**しておくことを強く推奨します。

---

## 0. 前提(フェーズ定義)

| | Phase 1(今回リリース) | Phase 2(将来検討) |
|---|---|---|
| 住所テロップ | **社内モニタ表示のみ**(放送に出さない) | **放送に出す** |
| 地図表示 | 社内モニタのみ | 当面は社内モニタのみ |
| 配布 | 系列局へ**無償配布** | 同左 |

**重要な原則**:
- **「配布」に伴う義務**(OSSライセンス等)は **Phase 1 から発生**します。無償でも配布は配布です。
- **「放送(公衆送信)」に伴う義務**(データの出典明記等)は **Phase 2 から発生**します。
- したがって Phase 1 で対応すべきは **配布義務のみ**、Phase 2 で **出典義務が追加**、という構造です。

---

## 1. Phase 1 の結論(社内モニタのみ・無償配布)

放送しないため、**「放送許諾」系の論点はすべて非該当**です。
残るのは**配布に伴う義務のみ**で、下記の設計により大半を回避できます。

### 1-1. 同梱しないもの(これで義務の大半が消える)

| 同梱しないもの | 理由 | 代替 |
|---|---|---|
| **GStreamer 本体** | LGPL。同梱するとライセンス全文+**ソース入手手段**の提供義務が発生 | 各局が公式インストーラで導入(手順書に明記) |
| **Blackmagic Desktop Video / SDK** | 再配布不可 | 各局が公式サイトから導入 |
| **Windows 同梱フォント** | フォントファイルの再配布は不可 | OFL系フォントを同梱 or 各局環境のフォントを使用 |
| **Google API キー** | キー共有は規約違反。貴社に全局分が課金される | 各局が自局キーを設定した場合のみ有効化 |

> この「同梱しない」設計により、**GStreamer の LGPL 配布義務は実質的に発生しません**
> (貴社が配布するのは自社コードのみで、外部プログラムを呼び出しているだけ)。
> ただし **THIRD_PARTY_NOTICES への記載は継続**してください。

### 1-2. 同梱するもの と 義務

| 同梱物 | ライセンス | 配布時の義務 | 対応 |
|---|---|---|---|
| numpy | BSD-3-Clause | 著作権表示+ライセンス文 | `LICENSES/` に添付 |
| Pillow | HPND(MIT系) | 同上 | `LICENSES/` に添付 |
| sounddevice / PortAudio | MIT | 同上 | `LICENSES/` に添付 |
| Python 本体 / tkinter・Tcl-Tk ※同梱する場合 | PSF / BSD系 | ライセンス同梱 | 各局が公式Python導入なら不要 |
| 市区町村境界データ<br>`muni_boundaries.json.gz` | 国土数値情報(国交省)<br>加工元 smartnews japan-topography(MIT) | **出典明記**、再配布可否を約款で確認 | 出典表記+MIT文添付。**版と約款を保管** |
| 市区町村コード表 `muni.json` | 国土地理院コンテンツ | 出典明記 | 「出典:国土地理院」 |
| 郡テーブル `gun.json` | **CC0-1.0**(geolonia由来) | **義務なし** | 記載のみ |
| フォント(同梱する場合) | SIL OFL(Noto)/ IPAライセンス | ライセンス同梱・改名制限等の順守 | **再配布可のもののみ**同梱 |
| 自社コード | 貴社所有 | — | 系列局向け利用条件(社内利用限定等)を添付 |

### 1-3. 配布時の既定値(重要)

| 設定 | 既定値 | 理由 |
|---|---|---|
| 逆ジオコーダ `--geo-mode` | **`offline`** | 全局が国土地理院APIを常用するのは規約・可用性の両面で不可 |
| 地図ソース | **オフライン境界地図**(または地理院タイル) | キー不要・課金なし・局ごとの契約不要 |
| Google マップ | **既定で無効** | 各局が自局キーを設定した場合のみ有効化 |
| 出力モード | Fill/Key または バーンイン(現場に応じて) | ライセンスとは無関係 |

### 1-4. 配布パッケージ構成(推奨)

```
heli_gps/
├── (自社コード一式)
├── nnn_decoder/data/        … muni.json / gun.json / muni_boundaries.json.gz
├── LICENSES/                … numpy, Pillow, sounddevice, PortAudio,
│                               (Python), (同梱フォント) の各ライセンス全文
├── THIRD_PARTY_NOTICES.md   … 出典・ライセンス一覧
└── README_SETUP.md          … 「GStreamer と Desktop Video は各局で公式版を導入」手順
```

**同梱しない**: GStreamer 本体 / DeckLink ドライバ・SDK / Windows 同梱フォント / Google API キー

## 2. Phase 2(住所テロップを放送に出す)で **追加**になること

第1章の配布義務は**そのまま継続**します。追加されるのは
**「放送に出るコンテンツの出典義務」**のみです。

| 追加論点 | 内容 | 対応 |
|---|---|---|
| **住所データの出典明記** | 放送に出る市区町村名は **国土数値情報(国交省)/ 国土地理院**由来。加工二次利用にあたり出典記載が条件 | 掲出方法を法務と決定(下記) |
| **出典の掲出方法** | テロップに毎回出すのは非現実的 | **番組クレジット / 局サイト / 社内資料**での記載で足りるか、**約款文言+法務**で確定 |
| **約款の適用範囲確認** | 使用中のデータ版の約款が「**公衆送信を含む二次利用**」を許すか | 条文確認+**使用版のスナップショット保存** |
| **フォントの放送使用可否** | 放送グラフィックへの使用可否は各EULA依存 | OFL系(Noto等)なら明確に可。Windows同梱フォントは要確認 |
| **精度・鮮度の免責** | 境界データは簡略化・更新遅延あり。誤った市区町村名が出る可能性 | 運用手順に確認フローを入れる(オペレーター目視確認等) |

### 参考:出典表記の文例
> 「この番組の位置情報は、国土数値情報(国土交通省)および国土地理院の
> データを加工して作成しています」

### もし将来「地図も放送に出す」場合(参考)
地図を放送に出す場合は、**地図ソースの放送可否**が新たな論点になります。

| 地図ソース | 放送可否 | 備考 |
|---|---|---|
| オフライン境界地図(現行) | ○(出典明記) | 追加コストなし |
| **地理院タイル** | **○(出典明記が条件)** | 無料・キー不要。**画面内に「出典:国土地理院」の掲出が必要** |
| Google マップ | **×〜△** | Googleの**放送向け許諾が別途必要**。キー同梱不可・従量課金のため無償配布と非適合 |

## 3. いま(Phase 1)のうちにやっておくと Phase 2 が楽になること

**後から変えると手戻りが大きい**項目です。今のうちに確定させることを推奨します。

| # | 項目 | 理由 |
|---|---|---|
| 1 | **フォントを OFL 系(Noto Sans CJK JP 等)に確定** | 放送移行時にフォントを変えると**見た目の再調整(サイズ・字間・位置)が全プリセットで発生**する。今決めれば手戻りゼロ |
| 2 | **データの版と約款を今スナップショット保存** | 後から「当時どの版・どの条文だったか」の立証が困難になる |
| 3 | **出典表記の文言と掲出方法を先に決めておく** | 放送直前に法務確認をすると進行が止まる |
| 4 | **Google をコア機能に組み込まない**(任意オプションのまま) | 放送移行時に**必ず外す/許諾取得が必要**になるため、依存を作らない |
| 5 | **地図をテロップ描画経路に混ぜない** | **現構成はすでに条件を満たしている**(地図は制御UIプロセス内の別ウィンドウで、放送に出る描画経路とは完全に分離)。この分離を維持すれば、Phase 2 で地図の放送可否問題が発生しない |
| 6 | **`--geo-mode offline` を既定のまま維持** | 放送時に外部API依存があると可用性・規約の両面でリスク |

> **補足(現構成の利点)**: 放送に出る映像は `SuperRenderer` が生成する
> テロップ画像のみで、地図は `control_ui` 側の別ウィンドウです。
> **地図が誤って放送に出る経路が構造上存在しない**ため、Phase 1 は安全側に倒れています。

## 4. コンポーネント別 早見表

| コンポーネント | ライセンス/根拠 | Phase 1(社内のみ) | Phase 2(放送) |
|---|---|---|---|
| GStreamer | LGPL-2.1 | 同梱しない → 義務なし(記載のみ) | 同左(変更なし) |
| GPLコーデック(x264等) | GPL | **不使用**(raw中心の現構成) | 同左。混ぜない運用を維持 |
| DeckLink ドライバ/SDK | Blackmagic独自 | 同梱しない | 同左 |
| numpy / Pillow / sounddevice / PortAudio | BSD-3 / HPND / MIT | ライセンス文添付 | 同左 |
| Python / tkinter | PSF / BSD系 | 同梱時のみ添付 | 同左 |
| 市区町村境界データ | 国土数値情報 + MIT | 出典記載(配布物内) | **+ 放送での出典明記** |
| 市区町村コード表 | 国土地理院 | 出典記載 | **+ 放送での出典明記** |
| 郡テーブル(gun.json) | CC0 | 義務なし | 義務なし |
| フォント | 各EULA | 再配布可のもののみ同梱 | **+ 放送使用可否をEULAで確認** |
| 地理院 逆ジオコーダAPI | 地理院地図向け提供 | **offline既定で不使用** | 同左(本番常用しない) |
| Google マップ | Google Maps Platform ToS | 各局キー設定時のみの任意機能 | 放送に出すなら**要許諾**(推奨しない) |
| 自社コード | 貴社所有 | 利用条件を添付 | 同左 |

## 5. 未確定・要確認事項(法務/各社へ)

1. **国土数値情報の約款**:使用中の版が「加工物の**再配布**」および「**公衆送信(放送)**」を許容するか(条文確認)
2. **国土地理院コンテンツ利用規約**:muni.js 由来テーブルの**再配布可否**と出典表記の要件
3. **出典の掲出方法**:番組クレジット/局サイトでの記載で要件を満たすか
4. **フォント**:同梱・放送使用するフォントのEULA(OFL系を選べば概ね解決)
5. **Google マップ(社内利用でも)**:自社ヘリの**リアルタイム位置追跡**が標準の Maps Platform 規約で許容されるか、**Asset Tracking 等の別ライセンス**が必要か
6. **系列局への配布条件**:自社コードの利用条件(社内利用限定・再配布禁止等)の文面
