# ライセンス整理（放送使用・地図スーパー選択制・Google不使用）

本書は、ヘリGPSスーパーシステムを **系列局へ無償配布** し、**放送でも使用する**
前提での、ライセンス・利用規約上の論点を整理したものです。

> **免責**: 本書は技術担当による整理であり、法的助言ではありません。最終判断は
> 各利用規約の**原文**と貴社法務でご確認ください。規約は改定されるため、
> **利用時点の条文を保存**しておくことを強く推奨します。

## 0. 前提条件（今回の整理の土台）

| 条件 | 内容 |
|---|---|
| **Google 関連サービス** | **不使用**（コードから完全に除去済み。アカウント連携・APIキー・課金なし） |
| **用途** | 社内モニタ表示 **＋ 放送（オンエア）** |
| **地図スーパー** | **選択制（ON / OFF）**。ONにすると地図が放送に出る |
| 配布 | 系列局へ**無償配布** |
| 外部通信 | **なし**（住所判定・地図描画はすべて同梱データによるオフライン処理） |

---

## 1. 結論

**すべて実施可能です。** そして重要な点として、

> **地図スーパーをONにしても、ライセンスの相手方は増えません。**
> 住所判定と地図描画は**同一の同梱境界データ**（国土数値情報由来）を使うためです。

追加で必要になるのは、新たな契約ではなく主に次の3点です。

1. **出典表記の掲出**（住所＝番組クレジット等／地図ON時＝画面内推奨）
2. **OFL系フォントの使用**（放送グラフィックで確実に使えるもの）
3. **精度に関する運用上の担保**（簡略化データのため境界付近で誤りうる）

## 2. 共通の義務（地図スーパー ON / OFF を問わない）

### 2-1. 配布に伴う義務（無償でも「配布」）

**同梱しないもの** — これで義務の大半が消えます。

| 同梱しない | 理由 | 代替 |
|---|---|---|
| **GStreamer 本体** | LGPL。同梱するとライセンス全文＋**ソース入手手段**の提供義務が発生 | 各局が公式インストーラで導入（`README_SETUP.md`） |
| **Blackmagic Desktop Video / SDK** | 再配布不可 | 各局が公式サイトから導入 |
| **Windows 同梱フォント** | フォントファイルの再配布は不可。**放送使用可否もEULA依存** | OFL系フォントを `fonts/` に同梱 |
| **外部地図サービス（Google等）** | アカウント連携・課金・キー共有の問題 | **不使用（除去済み）**。同梱データで完結 |

**同梱するもの と 義務**

| 同梱物 | ライセンス | 義務 |
|---|---|---|
| numpy | BSD-3-Clause | 著作権表示＋ライセンス全文（`LICENSES/`） |
| Pillow | HPND（MIT系） | 同上 |
| sounddevice / PortAudio | MIT | 同上 |
| Python / tkinter ※同梱時 | PSF / BSD系 | 同上（各局が公式Python導入なら不要） |
| 市区町村境界データ<br>（**行政区域データ N03 第3.0版**） | 国土数値情報（国交省）＋加工元 japan-topography（クレジット不要と明示） | **出典明記＋加工表記**。再配布は**オープンデータ区分のため可**（確認済み） |
| 市区町村コード表 `muni.json`<br>（**地理院地図 `muni.js`**） | 国土地理院コンテンツ（PDL1.0準拠） | **出典明記＋加工表記**。再配布可 |
| 郡テーブル `gun.json` | **CC0-1.0** | **義務なし** |
| **OFLフォント**（`fonts/`） | SIL OFL 1.1 | **OFL全文（`OFL.txt`）の同梱が必須** |
| 自社コード | 貴社所有 | 系列局向け利用条件を添付 |

### 2-2. 放送に伴う義務

| 項目 | 内容 | 対応 |
|---|---|---|
| **住所データの出典明記** | 放送に出る市区町村名は国土数値情報／国土地理院由来 | 掲出方法を法務と決定（番組クレジット等） |
| **約款の適用範囲** | 使用中のデータ版が「**公衆送信を含む二次利用**」を許すか | 条文確認＋**使用版のスナップショット保存** |
| **フォント** | 放送グラフィックへの使用可否はEULA依存 | **OFL系（Noto等）を使用**。Windows同梱フォントは使わない |
| **精度・鮮度** | 境界データは簡略化・更新遅延あり。境界付近で誤った市町村名が出る可能性 | 運用手順にオペレーターの目視確認を入れる |
| **適用限界の継承・伝達**（約款 第2条の義務） | 代表点は**街区・大字レベル（概ね数100m）の公差**、**1〜5年のタイムラグ**を持つ。これを**最終利用者まで継承・伝達**する義務がある | `TERMS_OF_USE.md` 第6条・`README_SETUP.md` に明記して系列局へ伝達（**対応済み**） |

#### 出典表記の文例（住所のみ・地図OFF時）
> 「この番組の位置情報は、「国土数値情報（行政区域データ）」（国土交通省）
> および国土地理院ウェブサイトのデータを加工して作成しています」

地図スーパーON時は画面内に
`出典:国土数値情報(国土交通省)・国土地理院を加工して作成` が自動描画されます（消去不可）。
文言・掲出先の根拠は `docs/ATTRIBUTION.md` §2。

## 3. 地図スーパー OFF / ON の差分 ← 本整理の核

| | **地図スーパー OFF** | **地図スーパー ON** |
|---|---|---|
| 放送に出るもの | 住所テロップのみ | 住所テロップ **＋ 地図（境界形状）** |
| 使用データ | 同梱境界データ（**判定のみ**） | 同梱境界データ（**判定＋描画**） |
| **ライセンスの相手方** | 国土数値情報／国土地理院 | **同じ（増えない）** |
| 追加費用 | なし | **なし** |
| 外部通信 | なし | **なし** |
| **出典表記** | 番組クレジット等で可 | **画面内（地図の隅）に自動描画・消去不可**（国土地理院が示す「表示画面に常時明示」を満たす） |
| 追加の注意点 | — | 境界形状そのものが公衆送信される。**簡略化されている旨**の理解、縮尺・方位の誤読防止 |
| 実装要件 | 現状のまま | テロップ描画経路に**地図を合成**し、**出典を焼き込む** |

### 3-1. 地図ONで何が変わるのか（技術的な意味）

現在の構成では、放送に出る映像は `SuperRenderer` が生成するテロップ画像のみで、
地図は `control_ui` 側の別ウィンドウです。つまり
**地図が放送に出る経路が構造上存在しません**（`ui_map` の参照元は `control_ui.py` のみ）。

地図スーパーを実装すると、**この分離を意図的に解除**することになります。
そのため、次を**設計要件**として組み込む必要があります。

1. **地図ON時、出典クレジットを地図インセット内に自動描画する**
   （オペレーターが誤って消せない形にする）
2. **地図は同梱境界データのみで描画する**
   → 外部タイル（地理院タイル等）を足すと**ライセンスの相手方と通信依存が増える**
3. **既定は地図OFF**（明示的にONにしたときだけ放送に出る）

### 3-2. 地図ON時の最重要確認事項

> **境界データを「地名の判定」に使うことと、「地図として描画して放送する」ことは
> 利用の深さが違います。** 後者は地理空間データそのものの公衆送信にあたります。
>
> **【2026-09-08 確認済み】** 国土数値情報の約款は公衆送信・翻案・商用利用を明示的に
> 許諾しており（条件＝出典記載＋加工した旨の記載）、行政区域データは
> **オープンデータ区分**です。国土地理院側も「システムでは測量成果が表示されている間、
> 表示画面に常時明示」という掲出場所の要件を示しており、地図インセット内の
> 自動描画クレジットがこれを満たします。**約款上の追加要件はありません。**
> 残るのは社内での掲出方法の最終決定のみです（`docs/ATTRIBUTION.md`）。

## 5. 前回整理からの変更点

前回は「Phase 1＝社内モニタのみ／Phase 2＝将来の放送」という段階構成でしたが、
**放送が当初から対象**になったため構成を変更しました。

| 項目 | 前回 | 今回 |
|---|---|---|
| 段階構成 | Phase 1 / Phase 2 に分割 | **廃止**（放送を当初から対象に一本化） |
| 住所の出典義務 | Phase 2 から発生 | **当初から発生** |
| OFLフォント | Phase 2 への「備え」 | **必須**（放送グラフィックで使うため） |
| 地図と放送経路 | 「構造上分離されており安全」 | **地図ONで意図的に解除**。出典焼き込みが新たな設計要件 |
| Google | 任意オプション扱いを検討 | **完全除去**（確認事項も解消） |
| 整理の軸 | フェーズ（時期） | **地図スーパー OFF / ON（構成）** |

1. ~~境界データを地図として描画し放送することの可否~~ → **約款で解決**。
   国土数値情報の利用規約（政府標準利用規約準拠版・令和2年4月1日制定）は
   「**複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。商用利用も可能です**」
   と明記（`docs/terms/agreement_01.txt`）。条件は**出典記載＋加工した旨の記載**。
   → 地図ON時は画面内クレジットを自動描画して充足。
   さらに国土地理院は「システムでは**表示画面に常時明示**、困難なら readme 等でも可」と
   掲出場所を明示（`docs/terms/gsi_2930_meizi.txt`）。地図ON時の画面内表示は上位要件を満たす。
2. ~~**【重要】行政区域データの「商用可／非商用」区分の確認**~~ → **2026-09-08 解決**。
   行政区域データのメタデータに「**平成30年度以降：適用する利用規約に基づく（オープンデータ）／
   上記以外：商用可**」と記載。使用中の令和3年基準データは**オープンデータ区分**のため、
   非商用区分の「複製物の再配布の除外」は**かからず、系列局への配布が可能**
   （`docs/terms/mlit_n03_v3_0_metadata.txt`）
3. ~~**国土地理院コンテンツ利用規約**：`muni.json` 由来テーブルの再配布可否と出典要件~~
   → **2026-09-08 解決**。規約（令和7年11月20日改正・PDL1.0準拠）により
   「複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。商用利用も可能です」。
   条件は**出典記載＋加工した旨の記載**のみ。出典記載例は
   「出典：国土地理院ウェブサイト（当該ページのURL）」（`docs/terms/gsi_content_terms.txt`）

5. **出典の掲出方法**：住所のみ（地図OFF）の場合の掲出先（番組クレジット／局サイト）を確定する
6. ~~**フォント**：`fonts/` に同梱するフォントのライセンス~~ → **2026-09-08 解決**。
   同梱 Noto Sans JP の name テーブルを実読し **SIL OFL 1.1**（name ID 13）、
