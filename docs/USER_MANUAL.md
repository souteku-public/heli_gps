# ヘリGPSスーパー 取扱説明書（操作編）

制御UI（`control_ui.py`）を操作する方向けの説明書です。
**インストールや配線**は `README_SETUP.md`、**権利関係**は `docs/LICENSING.md`
を参照してください。

---

## 1. このソフトは何をするものか

ヘリコプターから送られてくる映像の**音声に埋め込まれたGPSデータ**を読み取り、
機体がいまどこを飛んでいるかを**住所の文字**にしてSDI映像に重ねます。

```
  ヘリ側                              地上側（このソフト）
  ┌──────────┐                      ┌────────────────────────┐
  │ GPS受信機 │                      │ ① 音声からGPSデータを復調 │
  │    ↓     │                      │ ② 緯度経度 → 住所に変換   │
  │ TC-GE30N │ 音声に変調            │ ③ 文字を描いてSDIに重ねる │
  │    ↓     │ ────── SDI ──────→   └────────────────────────┘
  └──────────┘                                  ↓
                                        「千葉・鴨川市上空」
```

ポイントは3つです。

- **住所は衛星から降ってくるのではありません。** ヘリから届くのは緯度・経度・高度
  だけで、住所はこのPCが地図データと照らし合わせて決めています。
- **時刻もヘリからは届きません。** GPSデータに時刻の項目が無いため、時刻スーパーは
  **このPCの時計**を表示します。PCの時計が狂っていると、そのままスーパーに出ます。
- **スーパーの見た目はこのUIで決めます。** 位置・文字サイズ・色・フォントなど。

## 2. 起動と終了

### 起動

用途に合わせて、フォルダ内のバッチファイルを**ダブルクリック**します。
どれを使うかで**出力の方式が決まります**（起動後にUIから切り替えることはできません）。

| 起動するもの | 出力 | 使う場面 |
|---|---|---|
| `start_heli_gst.bat` | **Fill/Key** 2系統 | 外部キーヤーで合成する通常運用 |
| `start_heli_burnin.bat` | **焼き込み** 1系統 | キーヤーを使わず、映像に直接重ねて1本で出す |
| `start_heli_preview.bat` | PC画面のみ | 送出せずに確認したいとき |

起動すると**2つの窓**が開きます。

- **黒いコンソール窓**… 動作ログ。普段は見なくて構いませんが、**閉じると送出も止まります**。
- **制御UI**… 操作する画面。こちらだけ閉じても送出は止まりません。

### 終了

コンソール窓を閉じる（または `Ctrl+C`）と送出が止まります。
制御UIは別途閉じてください。

## 4. 受信状態の見かた（画面下の帯）

いちばん左のランプが現在の状態です。

| 表示 | 色 | 意味 | どうするか |
|---|---|---|---|
| **● 受信中** | 緑 | GPSデータが正常に届いている | 正常です |
| **● GPS途絶(直近を保持)** | 赤 | データが途切れた。**直前の住所をそのまま出し続けている** | 下記「5. 受信が途切れたとき」参照 |
| **● アプリ未接続/停止** | 灰 | 制御UIが送出側と話せていない | コンソール窓が開いているか確認 |

帯にはこのほか、現在のスーパー文字、緯度・経度・高度、度分秒（DMS）表記、
測位状態（正常／バックアップ／使用不能）、捕捉衛星数が並びます。

> **「● アプリ未接続/停止」が出たら**
> 制御UIは送出側と通信できていません。UIで何を変えても**スーパーには反映されません**。
> コンソール窓が閉じていないか、エラーで止まっていないかを先に確認してください。

## 5. 受信が途切れたとき（重要）

ヘリが山陰に入る、SDIが瞬断する、といった理由でGPSデータが途切れることがあります。
このとき**すぐにスーパーを消すと、短い瞬断でも画面がチラつきます**。
そのため、次のように段階的に動きます。

```
 受信途絶
   │
   ├─ 0秒 ────────────── 5秒 ───────────────── 20秒 ─────→
   │                      │                      │
   │  何も変わらない       │  赤ランプに変わるが    │  「受信途絶時の表示」
   │  （緑ランプのまま）   │  スーパーは出たまま    │  に切り替わる
   │                      │                      │
   └─ 住所を表示し続ける ───────────────────────┴─ 設定した文字（既定は空＝消える）
```

| 経過 | 画面下のランプ | 放送に出るスーパー |
|---|---|---|
| 0〜5秒 | ● 受信中（緑） | 直前の住所のまま |
| 5〜20秒 | ● GPS途絶(直近を保持)（赤） | **直前の住所のまま** |
| 20秒〜 | ● GPS途絶(直近を保持)（赤） | **「受信途絶時の表示」の文字**（既定は空＝スーパーが消える） |

- つまり **位置情報が取れなくなってから約20秒後**に、「受信途絶時の表示」で設定した
  文字に切り替わります。
- 既定ではこの欄は**空**なので、20秒後にスーパーが**消えます**。
- 20秒以内に受信が戻れば、何事もなかったように住所の表示が続きます。

### 「受信途絶時の表示」の決めかた

「住所」欄のいちばん下にあります。文字を入れて `Enter` または **適用** を押すと、
**すぐに反映されます**（「決定」は不要）。

| 設定例 | 20秒後の画面 | 向いている運用 |
|---|---|---|
| （空欄・既定） | スーパーが消える | 誤った位置を出したくない。いちばん安全 |
| `受信不良` | 「受信不良」と出る | 消えた理由を視聴者／スタジオに伝えたい |
| `中継中` | 「中継中」と出る | 位置は伏せつつ、スーパー枠を保ちたい |

> **なぜ古い住所を20秒も出し続けるのか**
> ヘリは時速200km程度で飛ぶため、20秒で約1km進みます。市区町村の粒度なら
> たいてい同じ自治体の中です。一方、瞬断のたびにスーパーが消えると画面が
> 落ち着きません。この兼ね合いで20秒としています。

## 6. 「決定（反映）」の意味 ― いちばん大事な操作

このUIには、**押した瞬間に放送に出る操作**と、
**「決定（反映）」を押すまで出ない操作**の2種類があります。

### すぐ反映されるもの（「決定」不要）

- 住所変換モード
- 住所の粒度（都道府県／市町村／市区町村／町丁目）
- ビットレート、音声ch
- 表示書式、受信途絶時の表示（`Enter` か **適用** ボタンで反映）

### 「決定（反映）」を押すまで反映されないもの

- **住所の見せ方**すべて（県を省く／市区町村を省く／区切り／海上／末尾）
- **見た目**すべて（表示ON/OFF、フォント、サイズ、太さ、揃え、透過、色、フチ）
- **位置**（ドラッグ、矢印キー、X/Y入力、縦に並べ直す）
- 時刻の書式・日付、局名の文字

未反映の変更があると、ボタンが

```
    決定（反映）  未反映 7 件
```

のように**件数つきで光ります**。これが出ている間、**画面のプレビューは新しい見た目、
放送に出ているのは古い見た目**です。

> **本番中の安全装置として使えます**
> 見た目をいろいろ試しても、「決定」を押さなければ放送は変わりません。
> 逆に言えば、**押し忘れると変更は一切反映されません。**
> 作業のあとはボタンが灰色（未反映ゼロ）になっているか確認してください。

## 7. 画面の各部

### 7-1. 住所

| 項目 | 説明 |
|---|---|
| **住所変換モード** | `オフライン(ネット不要)` … 同梱の地図データだけで判定。**通常はこれ**。<br>`自動(ネット時は町丁目)` … ネットがあれば町丁目まで、無ければオフライン。<br>`オンライン(地理院API)` … 常に国土地理院のAPIを使う。ネット必須。 |
| **住所の粒度** | どこまで細かく出すか。`都道府県` / `市町村(政令市は市まで)` / `市区町村(区あり)` / `市区町村(区・郡あり)` / `町丁目(要ネット)`。既定は**市町村**。 |
| **ビットレート** | ヘリ側エンコーダの設定に合わせます。通常 **1200 bps**。 |
| **音声ch** | GPSデータが入っているチャンネル。**CH1から数えた番号**で指定します。既定は **CH3**。 |
| **表示書式** | スーパー文字の組み立て方。既定 `{address}{suffix}`。<br>使える差し込み: `{address}` 住所 / `{suffix}` 末尾の語 / `{alt}` 高度m / `{lat}` `{lon}` 緯度経度 / `{sats}` 衛星数。<br>例: `{address}{suffix}　高度{alt}m` → 「千葉・鴨川市上空　高度300m」 |
| **受信途絶時の表示** | 「5. 受信が途切れたとき」参照。 |

> **音声chが合っていないと何も出ません。** コンソール窓には1秒ごとに
> `[audio] ch levels(CH1..): 0.000 0.000 0.412 ...` のように各chのレベルが
> 出ます。**数字が動いているch**がGPSのチャンネルです。

### 7-2. 住所の見せ方

同じ「千葉県鴨川市」でも、設定で表記が変わります。
欄の下に**いまの設定での見本**が陸上・海上の2通りで出るので、見ながら決められます。

| 項目 | 既定 | 効果 |
|---|---|---|
| 「県・都・府」を省く | **ON** | 千葉県 → 千葉 |
| 「市・区・町・村」を省く | **OFF** | ONにすると 鴨川市 → 鴨川 |
| 区切り | **・（中黒）** | 都道府県と市区町村の間。`区切りなし` / `・` / `　（スペース）` |
| 海上 | **沖** | 海上と判定されたときに付ける語。`沖` / `沿岸` / `付けない` |
| 末尾に付ける | **ON** / `上空` | 文字列の最後に付ける語。文字は自由に変えられます |
| 海上のときは末尾を付けない | **OFF** | ONにすると「茨城・鹿嶋沖上空」→「茨城・鹿嶋沖」 |

既定の組み合わせでは次のように出ます。

```
   陸上:  千葉・鴨川市上空
   海上:  茨城・鹿嶋沖上空
```

### 7-3. 表示する3つの項目

**住所・時刻・局名**の3つを、それぞれ独立に設定できます。横に3列並んでいます。

- 各列の先頭の**「○○を表示」チェック**でON/OFF。
- **フォント**… 一覧には原則、放送で使って問題のないものだけが出ます。
  画面下の「その他のフォントも表示（EULA要確認）」にチェックを入れると
  PCに入っている全フォントが出ますが、**個別にライセンス確認が必要**です。
  確認が必要なフォントを選ぶと注意書きが表示されます。
- **サイズ / 太さ / 揃え / 透過% / 文字色 / フチ色 / フチ太さ / X・Y**
- **時刻**だけ: 書式（`分まで 12:34` / `秒まで 12:34:56`）と日付（`なし` / `11/4` / `11月4日`）
- **局名**だけ: 表示する文字（既定「日本テレビ」）

既定では3項目とも**同じ位置・同じ大きさ・同じ色で左下に縦並び**です。

> **時刻はこのPCの時計です。** ヘリから時刻は届きません。
> 本番前にPCの時計が合っているか確認してください。

### 7-4. 配置

画面右上のプレビューで、スーパーの位置を**見たまま**決められます。

| 操作 | 動作 |
|---|---|
| 文字をクリック | その項目を選択 |
| ドラッグ | 動かす |
| 矢印キー | 1px ずつ移動 |
| `Shift` + 矢印キー | 10px ずつ移動 |
| X / Y 欄に直接入力 | 数値で指定（1920×1080 のピクセル座標） |
| **［縦に並べ直す］** | 表示中の項目を、選択中の項目を先頭に**きれいに縦並び**にし直す |

枠線はセーフエリアの目安です。プレビューは実際のフォントで描かれます。

### 7-5. 番組プリセット（3つ）

番組ごとに**見た目と住所の見せ方をまるごと**記憶できます。

- **保存**… いまの設定をそのプリセットに書き込む
- **呼出**… そのプリセットを読み込む（読み込んだ直後は**未反映**なので、
  放送に出すには **決定（反映）** を押します）
- 枠の名前は自由に書き換えられます（例: 報道、情報、スポーツ）

### 7-6. 既定として保存

いまの設定を**次回起動時の初期値**にします。保存先は
`ui_settings.json`（`control_ui.py` と同じフォルダ）です。

### 7-7. その他（ヘッダ）

- **ダークモード**… 画面の明暗を切り替え。スーパーの見た目には影響しません。
- **文字 小/中/大**… **操作画面の文字**の大きさ。スーパーの文字サイズではありません。
- **地図**… 現在地を地図で確認する別窓。**モニタ専用で、放送には一切出ません。**

## 8. よくある操作

### 住所を「千葉県鴨川市上空」の形にしたい

「住所の見せ方」で

- 「県・都・府」を省く → **OFF**
- 区切り → **区切りなし**

にして **決定（反映）**。

### スーパーを一時的に消したい

「住所」列の先頭「**住所を表示**」のチェックを外して **決定（反映）**。
時刻・局名も同様に個別に消せます。

### 高度も一緒に出したい

「住所」欄の**表示書式**を

```
{address}{suffix}　高度{alt}m
```

にして `Enter`。（表示書式は「決定」不要ですぐ反映されます）

### 位置を元の既定に戻したい

**［縦に並べ直す］** を押すと3項目がきれいに縦並びに戻ります。
その後 **決定（反映）**。

## 9. 困ったとき

| 症状 | 確認すること |
|---|---|
| スーパーが出ない | ①ランプが「● アプリ未接続/停止」でないか ②**音声ch**は合っているか（コンソールのレベル表示を確認） ③「住所を表示」のチェックが外れていないか |
| UIで変えても放送が変わらない | **「決定（反映）」に件数が出ていませんか。** 押してください |
| ランプが赤のまま | SDI入力とヘリ側送信を確認。20秒で「受信途絶時の表示」に切り替わります |
| 時刻がずれている | **PCの時計**を合わせてください（ヘリ由来ではありません） |
| 住所が実際と違う | 「住所の粒度」を確認。海上では市区町村名＋「沖」になります |
| 選びたいフォントが一覧に無い | 画面下「その他のフォントも表示（EULA要確認）」にチェック。ただし**ライセンス確認が必要**です |
| 映像の色が変わって見える | 焼き込み出力では、入力の色をそのまま通す設定が既定です。変わる場合は `start_heli_burnin.bat` の `COMPFORMAT` が `auto` になっているか確認してください |
| 映像がカクつく | 本来は制御UIを開いたままでも滑らかに出ます。続く場合はコンソールのエラー表示を確認してください |
| コンソールにエラーが出て止まった | エラーの意味と対処がコンソールに日本語で出ます。`check_signal.bat` で入力だけを切り分けられます |

> **送出が止まるとGPS受信も止まります。**
> 映像出力と音声取り込みは同じ処理の中にあるため、出力でエラーが起きると
> GPSも受からなくなります。「急にスーパーが出なくなった」ときは、
> まずコンソール窓にエラーが出ていないか見てください。
